# Медицинский центр «Планета Здоровья» — сайт

Редизайн сайта planeta-zdorov.ru (Красноярск) на Node.js + Express + SQLite, с полным
прайс-листом (5 разделов, 33 позиции), профилями специалистов, отзывами пациентов,
формой записи на приём и админ-панелью.

## Стек

- Express (сервер, роуты, API)
- better-sqlite3 (БД, режим WAL)
- express-session + bcryptjs (авторизация админа)
- express-rate-limit (защита от подбора пароля)
- helmet (security headers, CSP)

## Что нового относительно оригинала

Оригинал был информационным сайтом на собственной CMS без структурированного
поиска по прайсу. На редизайне добавлено:

1. **Форма записи на приём** (`/api/leads`) — выбор направления или специалиста,
   удобное время, согласие на обработку персональных данных (152-ФЗ).
2. **Прайс-лист с поиском** (`/tseny`) — аккордеон из 5 разделов и 33 позиций
   с быстрым поиском по названию вместо длинной таблицы.
3. **Админ-панель** — заявки, прайс-лист (CRUD), специалисты, отзывы (просмотр),
   настройки сайта редактируются без правки кода.

## Медицинская осторожность

На каждой странице с направлениями лечения и на странице цен присутствует дисклеймер
«Имеются противопоказания. Необходима консультация специалиста.» — также
продублирован в подвале сайта. Формулировки о направлениях не обещают излечения.

## Локальный запуск

```
npm install
npm run seed    # создаёт БД, наполняет реальными данными, создаёт админа
npm start       # http://localhost:3504
```

Админ-панель: http://localhost:3504/admin — логин/пароль по умолчанию `admin` / `planeta2026`
(указаны в `.env.example`, обязательно смените перед реальным использованием).

## Перед деплоем — обязательно

1. Скопировать `.env.example` в `.env`, задать реальный `SESSION_SECRET` (длинная случайная строка).
2. Сменить пароль администратора через админ-панель.
3. Canonical/`robots.txt`/`sitemap.xml` уже указывают на `https://planetazdorovya-site-1.onrender.com`
   (демо-домен на Render); при переезде на собственный домен — заменить везде на него.
4. Проверить и при необходимости обновить ссылку на карту (`map_embed_url` в настройках) —
   координаты сейчас точно наведены на ул. 2-я Огородная, д. 22А, Красноярск (подтверждено
   независимо через Яндекс.Карты и 2ГИС).

## Деплой на PaaS (Render и подобные)

1. Создать новый Web Service, подключить репозиторий.
2. Build command: `npm install && npm run seed` (seed идемпотентен — безопасно
   запускать при каждом деплое, данные не задвоятся).
3. Start command: `npm start`.
4. Задать переменные окружения (`SESSION_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`,
   `NODE_ENV=production`) в панели хостинга — см. `render.yaml`.
5. **Важно**: SQLite-файл должен жить на постоянном (не эфемерном) диске — на части
   бесплатных тарифов PaaS файловая система сбрасывается при каждом деплое.

## Деплой на VPS

1. Установить Node.js, склонировать репозиторий, `npm install`, `npm run seed`.
2. Установить PM2 (`npm install -g pm2`), запустить `pm2 start ecosystem.config.js` (при
   необходимости создайте файл по аналогии с другими сайтами очереди).
3. `pm2 save && pm2 startup` — чтобы сайт поднимался сам после перезагрузки сервера.
4. Настроить nginx как реверс-прокси на порт из `.env` (`PORT=3504`), выпустить
   HTTPS-сертификат (Let's Encrypt/certbot).

## Резервное копирование

`npm run backup` — создаёт снапшот БД в `data/backups/` (хранит последние 14 копий).
Поставьте эту команду в cron на хостинге (например, раз в сутки).

Восстановление: остановить сервер → удалить `*.db-wal`/`*.db-shm` → скопировать нужный
файл из `data/backups/` поверх `data/planetazdorovya.db` → запустить сервер заново.

## Дизайн

Направление «Ось движения»: клиника специализируется на ортопедии, неврологии,
экспресс-ортезировании и ботулинотерапии — то есть на биомеханике тела и высокоточных
вмешательствах. Сквозной графический мотив — гониометр (инструмент измерения угла
сустава): дуга с делениями и опорная точка, используемая как фон hero-секции и в
логотипе. Палитра: графитово-угольный `#1B2430`, тёплая бумага `#F5F0E7`, сигнальный
коралл `#E2543F` (метка на теле перед инъекцией/разметкой ортеза), приглушённый
диагностический синий-серый `#5B7A8C`, тёплый янтарь `#D9A34A` для детских программ.
Шрифты — 'Newsreader' (издательский serif для заголовков), 'IBM Plex Sans' (тело
текста), 'IBM Plex Mono' (цифры прайс-листа и измерения). Палитра построена заново,
не заимствована из оригинального логотипа клиники (глобус+руки, бирюзово-зелёный) —
подробности почему см. в комментарии в начале `public/styles.css` и в финальном отчёте
по проекту.
